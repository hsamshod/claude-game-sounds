# Добавление звукового пака

Источник звуков только zvukipro.com. Пак это словарь «категория → номера звуков» в `hooks/register.tsx` плюс ветка в `download-sounds.sh`. Номер `N` это порядковый номер звука на странице, файл лежит в `sounds/<ключ>/N.mp3`.

## 1. Входные данные

Нужны три вещи. Чего нет, спроси:

- URL страницы zvukipro.com со звуками;
- ключ пака, `[a-z0-9]+`, например `dota`;
- заголовок для UI, например `Dota 2`.

Если ключ уже есть в `PACKS` в `hooks/register.tsx`, остановись и скажи об этом.

## 2. Разбор страницы

```bash
bash .claude/skills/add-sound-pack/parse-zvukipro.sh <url>
```

Скрипт печатает `N<TAB>id<TAB>название`. Покажи пользователю число звуков. Если вывод пустой или число явно не сходится со страницей, разметка изменилась: не гадай, а посмотри HTML и почини скрипт.

## 3. Раскладка по категориям

Предложи таблицу для всех 11 категорий. Смысл категорий описан в README, в таблице «Категории»: `start, planStart, planReady, task, done, waiting, limit, error, death, fx, end`.

- Ни одна категория не остаётся пустой: тип `satisfies Record<keyof typeof WARCRAFT3, …>` пустую не пропустит, а на пустое событие не будет звука.
- Частое событие (`task`) можно взвесить повторами номеров, как в `WARCRAFT3.task`.
- Звуки, которые никуда не подошли, перечисли отдельно: в `download-sounds.sh` они не попадут.

**Дождись подтверждения или правок пользователя**, и только потом меняй файлы.

## 4. Правки

1. `download-sounds.sh`: новая ветка `case` с `PAGE` и `SOUNDS` в формате `номер:id` (только используемые номера, по 10 пар в строке, как у существующих паков). Добавь ключ в сообщение `неизвестный пак … (доступны: …)`, обнови строку «Использование» в шапке.
2. `hooks/register.tsx`:
   - словарь `<KEY>` (UPPER_SNAKE) с комментарием `// название` у каждого номера и окончанием `as const satisfies Record<keyof typeof WARCRAFT3, readonly number[]>`;
   - добавь пак в `PACKS`, `PACK_TITLES` и `PACK_MARKERS`. Маркер это файл с **максимальным** номером из `SOUNDS`: скрипт качает по возрастанию, так что он появляется последним;
   - обнови `description` и `argumentHint` команды `sound-pack` (`argumentHint` строится из `PACKS` сам).
3. `.claude-plugin/plugin.json`: ключ в `userConfig.pack.options`, `description` у `pack` и у плагина, минорный bump `version`.
4. `.claude-plugin/marketplace.json`: оба `description`.
5. `README.md`: число паков во вступлении, примеры `/sound-pack <ключ>`, ссылка на страницу в абзаце про добавление звуков, шаг 3 промпта установки.

Чужие незакоммиченные правки в этих файлах не трогай.

## 5. Проверка

```bash
bash download-sounds.sh <ключ>      # ожидаем «ошибок: 0»
ls sounds/<ключ>                    # есть mp3 и файл-маркер из PACK_MARKERS
claude plugin validate .
```

Попроси пользователя перезапустить Claude Code и выполнить `/sound-pack <ключ>`: ответ должен быть `Пак: <заголовок>`. Не коммить без просьбы.
