# warcraft-sounds

Мод для Claude Code: реплики из Warcraft III на события сессии (старт, планирование, задача, готово, лимит, ошибка). Работает в терминале и во вкладке Code в Claude Desktop на macOS, звук играет через `afplay`.

## Как настроить звуки под себя

Все соответствия «событие → звуки» лежат в начале файла `hooks/register.tsx`, в словаре `SOUNDS`. Каждая категория это событие, а числа в ней это номера звуков. Номер `N` означает файл `sounds/wN.mp3`, рядом с каждым номером в комментарии написано, что это за фраза:

```ts
task: [
  39, // «Опять работа?»
  40, // «Готов вкалывать»
],
done: [
  35, // «Готово»
],
```

- **Перенести звук в другую категорию.** Вырежи строку с номером и вставь в нужный список. Больше ничего менять не надо.
- **Услышать фразу чаще.** Продублируй её строку несколько раз. Звук выбирается случайно из списка, поэтому два вхождения дают вдвое больший шанс.
- **Убрать звук.** Удали строку или закомментируй её. Не оставляй список пустым: на такое событие звука не будет.
- **Добавить звук, которого нет в списках.** Номера всех звуков взяты со [страницы zvukipro.com](https://zvukipro.com/games/2214-zvuki-iz-igry-warcraft-3.html). Номера 20, 41 и 44 по умолчанию не скачиваются. Чтобы добавить любой другой звук, впиши пару `номер:id` в `download-sounds.sh`, запусти скрипт и добавь номер в нужную категорию.
- **Применить изменения.** Перезапусти Claude Code. Если мод подключён с хот-релоадом, он перечитается сам.
- **Проверить правку.** Команда `claude plugin validate .` сообщит об ошибке в файле.

Категории:

| Категория | Когда играет |
|---|---|
| `start` | старт сессии |
| `planStart` | вход в режим планирования |
| `planReady` | план готов |
| `task` | начало задачи (отправка промпта) |
| `done` | работа закончена |
| `waiting` | на экране диалог разрешения |
| `limit` | окно лимита подписки заполнено на 90% и больше |
| `error` | ошибка хода или отказ модели |
| `death` | субагент завершился с ошибкой |
| `fx` | вызовы Edit и Write |
| `end` | конец сессии |

## Установка

Звуки Warcraft III принадлежат Blizzard и в репозиторий не входят. Их скачивает скрипт.

```bash
git clone https://github.com/hsamshod/claude-warcraft-sounds.git
cd claude-warcraft-sounds
./download-sounds.sh
claude --plugin-dir "$PWD"
```

Чтобы мод грузился в каждой сессии без флага, добавь путь в `~/.claude/settings.json`:

```json
{ "env": { "CLAUDE_CODE_PLUGIN_DIRS": "/абсолютный/путь/к/claude-warcraft-sounds" } }
```

## Прочие параметры

Они тоже в начале `hooks/register.tsx`:

- `LIMIT_PERCENT` — при каком заполнении окна лимита играть звук (по умолчанию 90).
- `CLIP_MS` — сколько мс после начала клипа пропускать необязательные звуки, чтобы они не накладывались (по умолчанию 2500). Старт, ошибка, лимит и конец сессии играют всегда.
