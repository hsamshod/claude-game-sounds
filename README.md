# warcraft-sounds

Мод для Claude Code: реплики из Warcraft III на события сессии. Работает в терминале и во вкладке Code в Claude Desktop (macOS, звук играет через `afplay`).

| Событие | Примеры реплик |
|---|---|
| Старт сессии | «Чего желает мой повелитель», «Что прикажете» |
| Начало планирования | «О, позабавимся», «Провижу грядущее» |
| План готов | «Лови ядро», «Да свершится предначертанное!» |
| Начало задачи | «Опять работа?», «Готов вкалывать» |
| Работа закончена | «Готово», «Постройка завершена» |
| Ждёт разрешения | «Чё надо, хозяин», «Чего хочешь, зайка» |
| Лимит подписки ≥ 90% | «Нужно больше золота» |
| Ошибка | «Error sound», «Нас атакуют» |
| Субагент упал | звуки смерти юнитов |
| Edit / Write | звуки стройки |
| Конец сессии | «Когда же кончится эта война» |

Звук выбирается случайно из списка категории; чтобы фраза звучала чаще, продублируй её номер в списке. Если клип играл меньше 2,5 с назад, новый пропускается (кроме старта, ошибки, лимита и конца сессии).

## Установка

Звуки Warcraft III принадлежат Blizzard и в репозиторий не входят. Их скачивает скрипт.

```bash
git clone https://github.com/hsamshod/claude-warcraft-sounds.git
cd claude-warcraft-sounds
./download-sounds.sh
claude --plugin-dir "$PWD"
```

Чтобы мод грузился в каждой сессии без флага, добавь путь в `~/.claude/settings.json`:

```json
{ "env": { "CLAUDE_CODE_PLUGIN_DIRS": "/абсолютный/путь/к/claude-warcraft-sounds" } }
```

## Настройка

Всё в начале `hooks/register.tsx`:

- `SOUNDS` — какие номера звуков играют на какое событие. Номер `N` это файл `sounds/wN.mp3`, номера взяты из списка на [zvukipro.com](https://zvukipro.com/games/2214-zvuki-iz-igry-warcraft-3.html).
- `LIMIT_PERCENT` — при каком заполнении окна лимита играть звук (по умолчанию 90).
- `CLIP_MS` — сколько мс после клипа пропускать необязательные звуки.

Проверка мода: `claude plugin validate .`
